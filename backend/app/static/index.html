🔐 Secure API Key Setup Instructions

To enable multimodal visual understanding, tone assessment, and deep semantic inspection:

  1. Open the .env file in the project root.
  2. Add your API keys: 
    # Recommended Primary Multimodal Model (fast, low cost)
GEMINI_API_KEY=your_gemini_api_key_here

# Alternative Multimodal Reasoning Model
OPENAI_API_KEY=your_openai_api_key_here

# Specialized NLP / Sentiment
HUGGINGFACE_API_KEY=your_hf_key_here
  3. Restart the backend or reload this page. The system will automatically detect the configured provider.
  4. Rule 10 & 11 Guarantee: If keys are absent, deterministic checks remain 100% active, and the AI features truthfully report their unconfigured state without fake percentages.
